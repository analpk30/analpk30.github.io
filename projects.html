Signalix

Signalix is an AI-powered company intelligence platform inspired by Bloomberg, Perplexity Finance, PitchBook, FinChat and AlphaSense. The MVP combines free public data sources into one provider-agnostic research dashboard for public companies.

MVP Scope
  • Executive company profile.
  • Financial statement trends and ratios.
  • Stock dashboard with price and moving-average views.
  • AI news summary and sentiment surface.
  • SEC filing list prepared for a future RAG chat.
  • Alternative data signals for patents, hiring, search interest and macro context.
  • AI health score, investment thesis, risk detection and Ask AI prompts.
  • FastAPI backend contract designed for free API adapters first and paid providers later.
Design Decisions
  • Provider-agnostic adapter layer: each data source (prices, filings, news, alternative data) sits behind one interface, so free APIs can be swapped for paid providers without touching the frontend contract.
  • Typed Pydantic response models validate every payload at the API boundary, keeping the dashboard and the backend in sync.
  • Explainable AI outputs: the health score, thesis and risk flags return the factors behind them, not just a number or a paragraph.
  • SEC filings are structured for retrieval from the start (chunking and embeddings in pgvector or FAISS), so the Ask AI chat can later cite the exact filing passage.
  • Caching and background jobs (Redis, Celery or FastAPI background tasks) are planned to stay within free-tier API rate limits.

MiniCloud

MiniCloud is a personal developer cloud platform built incrementally on top of existing open-source infrastructure. The long-term goal is a one-command developer experience: minic deploy ./my-fastapi-app ends with a live HTTPS address such as my-fastapi-app-a81x.apps.mycloud.dev.

Technical Highlights
  • Building MiniCloud, a lightweight personal developer cloud platform that deploys containerized applications to a single VPS using k3s, Traefik, wildcard DNS, and automatic HTTPS.
  • Designed a FastAPI-based control plane and CLI workflow to turn developer intent into Kubernetes Deployments, Services, Ingress routes, health checks, resource limits, and public application URLs.
  • Applied DevOps and platform-engineering practices including containerization, Kubernetes orchestration, TLS automation with cert-manager and Let’s Encrypt, secure secret handling, and cost-efficient single-node infrastructure design.
